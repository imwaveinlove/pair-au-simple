# 페어 AU

페어 두 사람의 **오리진**을 맨 위에 두고, 아래로 **AU 카드**를 한 장씩 쌓는 한 장짜리 페이지입니다.
설치도 서버도 필요 없습니다. `index.html` 파일 하나가 전부입니다.

**→ https://imwaveinlove.github.io/pair-au-simple/**

## 화면 구성

### 오리진

두 사람이 좌·우로 마주 봅니다. 각자 사진 한 장, 이름, 한 줄 소개, 인물 색을 정합니다.
사진은 끌어서 옮기고 휠이나 슬라이더로 확대합니다(두 번 누르면 원위치).
그림은 잘리지 않고 틀 안에 전체가 담기며, 꽉 채우고 싶을 때 확대해서 맞춥니다.

두 사람 사이에는 **서로를 향한 감정 화살표**가 놓입니다. 위는 왼쪽 사람이 오른쪽에게,
아래는 그 반대. 글자를 눌러 바로 고치고, 화살표 색은 그 감정을 품은 쪽의 인물 색을 따릅니다.

이름 옆 알약 버튼으로 **말풍선을 사람마다 따로 켜고 끕니다.** 말풍선은 각자 얼굴 쪽으로
꼬리를 물고 안쪽에 떠서, 두 사람이 서로에게 한마디 던지는 모양이 됩니다.
말풍선 안을 눌러 바로 적고, 줄 수만큼 자동으로 늘어납니다.

### AU 카드

이름 + 태그 + 설명 한 칸에, 그림은 카드 머리의 단추로 **세 가지 중에 고릅니다.**

| 방식 | 모양 |
| --- | --- |
| **한 장** | 그림 한 장이 카드 위에 들어갑니다. |
| **없음** | 그림 없이 설정만 적는 카드. |
| **페어** | 오리진처럼 두 사람의 그림을 하나씩, 가운데에 서로를 향한 감정 화살표. |

방식을 바꿔도 넣어 둔 그림은 지워지지 않아 언제든 되돌릴 수 있습니다.
그림 자리는 고정 크기이고, 그 안에 그림 전체가 잘리지 않고 들어갑니다.
카드 아래 `◀ ▶` 로 순서를, `⧉` 로 복제, `✕` 로 삭제하고, `＋ AU 추가` 로 카드가 계속 붙습니다.

## 그 밖에

| 기능 | 설명 |
| --- | --- |
| 출처 한 줄 | 그림 아래 가운데 정렬된 캡션. 그린이·커미션 출처를 적어 둡니다. |
| PNG 저장 | 지금 화면을 이미지 한 장으로 내려받습니다. 도구·입력칸은 빠집니다. |
| 텍스트 복사 | 오리진 → 말풍선 대사 → AU 목록 순서의 마크다운으로 복사합니다. |
| 테마 | 백코 · 블루밍 · 블루레몬, 그리고 색 두 개로 만드는 **그라데이션**. |

그라데이션은 고른 두 색에서 배경뿐 아니라 글자색·카드색·선색·강조색까지 뽑아냅니다.
어두운 두 색을 고르면 어두운 판으로, 밝은 색을 고르면 밝은 판으로 알아서 뒤집혀
어떤 색을 골라도 글씨가 묻히지 않습니다.

## 쓰는 법

`index.html` 을 브라우저로 열면 끝입니다. 위 주소로 바로 써도 됩니다.

- 적은 내용과 넣은 사진은 **그 브라우저의 localStorage 에만** 저장됩니다.
  서버로 올라가지 않고, 다른 기기·다른 브라우저와 공유되지 않습니다.
  브라우저 데이터를 지우면 함께 지워지니, 남겨 둘 것은 `PNG 저장` 이나 `텍스트 복사` 로 빼 두세요.
- 사진은 넣을 때 크기를 줄여 담습니다(AU 1000px, 인물 480px). 저장 공간이 넉넉하지 않으니
  아주 큰 사진을 여러 장 넣으면 저장에 실패할 수 있습니다.
- PNG 로 저장하면 웹폰트가 그림 안으로 들어가지 못해 **글꼴만 시스템 글꼴로** 바뀝니다.
  레이아웃과 색은 화면 그대로입니다.
